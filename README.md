> [!WARNING]
> 
> **本项目无开源许可证，禁止二次分发，仅作「学习＆存档」使用。**

- **茯苓规则**为`项目维护者`网络冲浪时抓取。
    - **自`2025年04月28日`起，本仓库`不再提供带有条目注释`的规则列表。**
    - 规则内容「拦截」：开屏广告、广告弹窗、广告SDK、网站内嵌广告。
    - 规则内容「允许」：应用接口、游戏接口、中国大陆网站、国际网站。
    - 规则内容「调试」：特殊环境下的Debug规则。
- **非茯苓规则**为**下列情况中**`其它作者`的**规则**收集。
    - 规则的「旧」版本。
    - 规则的「合并」版本。
    - 已经「找不到出处」的规则。
- **部分`非茯苓规则`存在`原项目`地址，推荐`优先使用`原项目内的规则。**
